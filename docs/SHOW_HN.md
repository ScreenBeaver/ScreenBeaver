**Title (plain):**

Show HN: Screen Beaver – open-source Windows studio that turns screen recordings into polished product demos

**Body:**

Screen Beaver is an open-source Windows desktop app for product demos. You record a window or screen, then polish in one timeline — auto zooms, captions, voiceover, frames, and local MP4 export. No cloud encode for the core studio.

Agents can drive demos hands-free over MCP (Cursor / Claude) while you watch.

Try it:

- Microsoft Store: https://apps.microsoft.com/detail/9P89CCNBVMVV
- Source: https://github.com/ScreenBeaver/ScreenBeaver
- Site: https://screenbeaver.com

Happy to answer questions about capture, MCP, or the editor.
